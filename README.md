# ARCHI-SPACE — Version 1

A bilingual review edition of the integrated physical–digital architectural learning website.

## Open and deploy

Open index.html in a browser. For GitHub Pages, upload this folder's contents to the publishing branch and configure Pages to serve that branch's root. For Netlify, deploy this folder directly with no build command. All media paths are relative, including on GitHub project pages.

## Files

- index.html: accessible application shell.
- styles.css: responsive white/lavender design system.
- app.js: bilingual content, seven sections, SPACE stage controls, resource filters, decision log and local progress.
- assets/: conceptual hero, source video stills, compressed SeVRa demonstration and SVG mark.
- evidence/: supplied ARCHI-KIT research paper.

## Content and evidence

The hero is AI-generated conceptual artwork, not documentary evidence. SeVRa is a user-supplied demonstration. ARCHI-KIT findings are reported perceptions, not measured ARCHI-SPACE improvements. SPACE activities and assessment suggestions are proposals. Confirm media permissions, team credits and all institutional approvals before public publication.

The AKRI reference is the verified 2025 guide; confirm the official 2026 guide before submission. Restricted curriculum PDFs are not included. Summaries require institutional confirmation.

## Editing

Edit English/Bahasa Malaysia pairs in app.js together. Keep tool names and the SPACE acronym unchanged. Replace local images without renaming paths or update the references. Add verified evidence with its source, population, method and limitations; do not fill gaps with invented figures.

## Privacy and limitations

Notes and preparation checkboxes stay in the current browser's localStorage; there is no database or remote submission. Clearing browser storage removes saved work. The text export preserves the decision log. External Google Fonts are optional and fall back to system fonts. This is not a live VR engine or an official AKRI portal.

## Validation

JavaScript syntax, both language renderers and local asset references were checked. Full browser/device interaction and accessibility audits are still required before public release.
